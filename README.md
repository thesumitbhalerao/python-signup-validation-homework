# Python Signup Validation

## 📌 About the Project
This is a Python homework project that validates user signup details using functions and conditional statements.

## 🎯 Requirements
- Username must contain more than 3 characters.
- Password must contain at least 8 characters.
- Password must contain at least one number.
- Email must contain the `@` symbol.

## 🛠️ Concepts Used
- Python functions
- User input using `input()`
- `if-else` statements
- String handling
- `len()`, `any()`, and `isdigit()`

## ▶️ How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python website.py
```

4. Enter your username, password, and email when prompted.

## ✅ Expected Output
If all validations pass:

```text
Your entered data is correct.
```

If any validation fails:

```text
Please try with different username, password, email.
```
